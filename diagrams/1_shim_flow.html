Shim 自分发 —— 硬链接拦截流程
用户敲下 node -v 后，系统到底做了什么
⌨️
用户敲命令
node -v
🔍
Shell 查找
PATH 中找 node
~/.pvm/shims/node
⚡
pvm 启动
硬链接 = pvm.exe
发现自己叫 node
📋
读取 .pvmrc
当前目录
node = 20.11.0
🎯
转发执行
真实二进制
installs/.../node.exe

关键设计

  • 硬链接，不是 Shell 脚本。nvm、asdf 的 shim 是 bash 脚本，Windows 跑不起来。PVM 的 shims/node 是 pvm.exe 的硬链接，Windows / macOS / Linux 一套逻辑，零 Shell 依赖。
  • 实时读取 .pvmrc。每次调用自动读当前目录的配置文件，cd 进去那一刻版本就已经对了，不需要手动 pvm use。
  • 零额外磁盘。所有 shim 指向同一个二进制，不占多余空间。
