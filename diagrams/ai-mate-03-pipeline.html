本地流水线：@ 引用串行 · & 并发 · 零手工引导
pvm.yaml 就是项目的操作说明书 —— AI 接手项目，一条命令跑完全程
pvm.yaml
# ① 串行：构建完成才继续 - "@build:pro" ① # ② 并发：测试与 lint 同时跑 - "@test:unit" & @lint ② # ③ 交付：一条命令出 5 平台 - "@pkg:go:pro" ③ # 上游任务均可独立执行： build:pro: [ pnpm run build:pro ] test:unit: [ vitest run ] lint: [ pnpm exec eslint . ] pkg:go:pro: [ pvm pack go --entry . ]
pvm run release:pro —— 执行时间线

总耗时 = build + max(test, lint) + pkg —— 并发段取最慢的一个，不是相加；
执行前 pvm 自动装齐 .pvmrc 声明的运行时，流水线里只有业务命令。

零手工引导

执行前自动装齐 .pvmrc 声明的运行时，AI 连「先装 node」这种环境命令都不用写。

pvm run --list 即能力清单

AI 接手陌生项目，一屏看到全部流水线，构建/测试/发布命令不再靠猜。

--dry-run 先看后跑

预览将要执行的命令序列再执行，AI 的每一步都透明可控。
