# 正向触发示例

以下提示词必须 100% 触发 code-env skill（环境检测流程）：

1. "帮我准备环境，git 地址是 https://e.coding.net/xxx/yyy.git，拉主分支建个修复缺陷的分支" — 完整流程触发：git/pvm 检测 → 拉码建分支 → 运行时 → 依赖 → 启动验证
2. "环境检测一下，确保 pvm 装好" — env-check 阶段触发：检测 git/pvm，未装则装
3. "初始化项目环境：clone 代码、建 fix 分支、装 node/pnpm、pnpm i，最后启动验证能跑" — 全 5 anchor 流程
4. "修复缺陷环境准备，git 地址发你了，环境搞好告诉我" — 流程触发（简式表述）
5. "这个 monorepo 哪些子目录要 pnpm i？装完把前端跑起来验证" — deps-install（形态识别）+ verify-run 阶段
6. "新机器，从零把开发环境搭起来" — 环境检测 + 安装全流程

# 要点

正向触发的共同特征：**多步骤环境准备**（检测/安装 + 拉码/分支 + 运行时/依赖/验证的组合），而非单项操作。
