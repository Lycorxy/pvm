# 正向触发示例

以下提示词必须 100% 触发 pvm-env-manager skill：

1. "帮我安装 pvm" — 自动检测当前 OS/CPU，安装匹配的最新稳定 Release，不追问架构
2. "在这台 M 系列 Mac 上安装 pvm" — 自动选择 `pvm-darwin-arm64`
3. "安装 pvm 0.0.1" — 自动检测平台和架构，固定安装 `v0.0.1`
4. "我需要 python 环境来跑这个脚本"
5. "我电脑上有 nvm，想换成 pvm，帮我卸载 nvm"
6. "这个项目需要 node 20，帮我切换版本"
7. "pvm 怎么更新到最新版"
8. "帮我把这个项目的运行时版本锁定"
9. "其他 skill 需要 python 3.12，先帮我装好环境"
